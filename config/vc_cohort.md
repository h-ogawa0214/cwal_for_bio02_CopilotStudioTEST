# VC陣 ウォッチ調査メモ（venture capital cohort）

対象は指定の46VC。取り上げるのは「●●に出資」等の**投資告知リリース**のみ（メンバー追加は対象外）。

方針: まず PR TIMES 企業別API（`source_type: prtimes_company`）で低コストにチェック。
`config.include_keywords`（`出資 / 資本参加 / リード投資 / 引受`）でタイトルを事前フィルタし、
イベント・採用・ファンド設立などをLLM前に落とす。全社まず `crawl_mode: shadow`。
PR TIMESに自社投稿が無いVCはウェブサイト個別調査に回す。
